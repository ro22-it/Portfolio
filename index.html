Супротек Ростов

Интернет-магазин · 2026

Интернет-магазин присадок и автохимии Suprotec для официального представителя в Ростове-на-Дону: каталог, корзина, оформление заказа с онлайн-оплатой, личный кабинет и админ-панель.

Тип
Интернет-магазин: сайт + сервер + база данных + платёжная система
Роль
Автор: вёрстка, серверная часть, база данных, интеграции
Стек
Node.js, Express, SQLite (sql.js), JWT, bcrypt, Multer, HTML/CSS/JS
Интеграции
ЮKassa (онлайн-оплата), Telegram-бот (уведомления о заказах)
В цифрах
8 страниц сайта
15 эндпоинтов API
11 товаров в 4 категориях
4 способа доставки, 3 способа оплаты
Репозиторий
github.com/ro22-it/rostov-suprotec

Что умеет магазин

  • Каталог с поиском и фильтром по категориям: для двигателя, трансмиссии, топлива, масла.
  • Страница товара с ценой, остатком на складе и подробным описанием.
  • Корзина, которая сохраняется в браузере между визитами.
  • Оформление заказа: самовывоз, СДЭК, Почта России или Яндекс Доставка; оплата онлайн через ЮKassa, наличными или переводом.
  • Регистрация и личный кабинет с историей заказов и бонусными баллами.
  • Админ-панель: добавление, редактирование и удаление товаров с фото, смена статуса заказа (новый, в обработке, отправлен).

Что было интересно сделать

  • Подключил платёжную систему ЮKassa: создание платежа, переход на оплату, приём уведомления (webhook) и проверку статуса.
  • Сделал Telegram-бота, который присылает продавцу сообщение о каждом новом заказе с контактами покупателя и составом.
  • Авторизация на JWT-токенах, пароли хранятся в виде хеша bcrypt, админские действия закрыты отдельной проверкой роли.
  • Загрузка фотографий товаров через Multer, настройки (ключи, порт) вынесены в переменные окружения.

Maison Parfums

Сайт подбора парфюма · 2026

Сайт-каталог, который помогает выбрать аромат по нотам, сезону, поводу и характеру, а потом сравнить несколько вариантов между собой.

Тип
Многостраничный сайт без сервера (статика)
Роль
Автор: идея, дизайн, вёрстка, логика, наполнение базы
Стек
HTML, CSS, JavaScript, Three.js (WebGL), Google Fonts
В цифрах
672 аромата в базе
≈ 480 нот в справочнике
3 страницы: каталог, аромат, сравнение
≈ 6 000 строк кода
Репозиторий
github.com/ro22-it/maison-parfums

Что умеет сайт

  • Подбор по полу, времени суток, сезону, поводу (работа, свидание, учёба…), нотам и типу аромата; в каждом фильтре можно выбрать несколько значений.
  • Поиск по названию и бренду, сортировка по популярности и новизне.
  • Страница аромата: пирамида нот (верх, сердце, база), аккорды в процентах, стойкость и шлейф по шкале 1–5, подходящие сезоны и поводы.
  • Справочник нот: при клике на ноту показывается, как она пахнет и к какому семейству относится.
  • Сравнение нескольких ароматов в таблице, общие ноты подсвечиваются.

Что было интересно сделать

  • 3D-флакон на Three.js с «каминным» светом и запасной картинкой, если браузер не поддерживает WebGL.
  • Анимированное интро и плавный переход от главного экрана к подбору по колесу мыши и свайпу.
  • Компактный формат базы: каждый аромат описан одной строкой через функцию-конструктор, данные разбиты на 10 файлов.
  • Адаптация под iPhone: экран заходит под статус-бар и панель Safari без белых полос.

Лапы, крылья и хвосты

Веб-сервис · практика · 2026

Сервис помощи животным: здесь можно найти питомца, разместить объявление о животном, которому нужен дом, и открыть или поддержать сбор денег на лечение.

Тип
Полноценный веб-сервис: фронтенд + REST API + база данных
Роль
Командный проект на практике; основной автор кода (43 из 51 коммита)
Стек
Python, FastAPI, PostgreSQL (psycopg), HTML/CSS/JS, Podman
В цифрах
13 эндпоинтов API
4 таблицы в базе
5 страниц интерфейса
37 проверок в скриптах тестов
Репозиторий
github.com/nikitatatata/praktika-ithub-kanban

Что умеет сервис

  • Регистрация и вход, профиль пользователя с контактами и описанием.
  • Объявления о животных: вид, порода, возраст, цена, стерилизация, фото. Каталог с фильтрами по виду, породе, возрасту и стерилизации и постраничным выводом.
  • Сборы средств: пользователь создаёт сбор на лечение животного, другие могут пожертвовать; прогресс сбора считается автоматически.
  • Личный кабинет: мои объявления, мои сборы, история пожертвований, избранное.

Что было интересно сделать

  • Спроектировал схему базы: пользователи, животные, сборы и пожертвования связаны внешними ключами с каскадным удалением.
  • Написал REST API на FastAPI и документацию к каждому эндпоинту (api_docs.md).
  • Сделал загрузку фотографий животных на сервер.
  • Покрыл API скриптами проверки на curl: позитивные сценарии и негативные (ошибки ввода, чужие данные, несуществующие записи).
